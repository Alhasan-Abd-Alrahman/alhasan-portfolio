# Alhasan — Frontend Developer Portfolio v2

A motion-led portfolio concept built with React, TypeScript, Vite, Tailwind CSS v4, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
npm run preview
```

## Design direction
- Deep navy / near-black surfaces, electric blue `#168BFF`, cyan highlights, white typography.
- Motion-rich hero: animated orbital rings, floating React/Vue chips, a code-window visual, and a blinking caret.
- Scroll-triggered reveal transitions, hover-responsive project cards, animated skill entries, moving specialty ticker, animated gradient text, and back-to-top control.
- Responsive mobile navigation and reduced-motion accessibility support.

## Content notes
- Update `src/data/portfolio.ts` to change skills, work history, and projects.
- Project visuals are original CSS-built illustrations rather than screenshots of real products. Replace them with genuine screenshots when available.
- The email CTA uses `mailto:` and does not submit to a backend.
- This version intentionally presents the CV as a story and proof of work, rather than placing the entire CV on the page.
